# Sponsor logos

Use PNG, JPEG, or WebP named after the sponsor or prefix. Matching ignores capitalization, spaces, punctuation, and accents: `Red-Bull.webp` matches Red Bull. Keep one matching file per logo; duplicate matches leave the logo blank.

Installed copies use the app-data `sponsors/` folder, accessible from JABS. Choose **Reload assets** after changing files. Only add logos you have permission to use or share.
