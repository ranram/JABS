# Sponsor logos

Use PNG, JPEG, or WebP named after the sponsor or prefix. Matching ignores capitalization, spaces, punctuation, and accents: `Red-Bull.webp` matches Red Bull. Keep one matching file per logo; duplicate matches leave the logo blank.

Open the `sponsors/` folder from **Media** in JABS. Installed copies keep it in the app-data directory. After changing files, return to JABS to load them, or choose **Media → Reload assets** to force a refresh. Only add logos you have permission to use or share.
