# Tournament logos

Place tournament and organizer logos in this folder as PNG, JPEG, or WebP files. JABS lists valid images in its logo selectors.

Installed copies use a `tourney-logos` folder inside the JABS app-data folder. Only add logos you have permission to display or share. Local logo files are not covered by JABS's Apache-2.0 license.

After adding, replacing, or renaming a logo, return to JABS to load the changes. Choose **Media → Reload assets** to force a refresh.
