# Sample winner stinger

The Stingers tab and toolbar menu are hidden as of JABS 1.6.4. Existing OBS setups still work. We may retire Stingers in a future release.

[Winner-Placeholder.webm](Winner-Placeholder.webm) is an eight-second transparent winner animation at `1920×1080`, without audio.

Open **Help → Set up stingers** and choose it as the Winner video to try playback and frame the player artwork. See the [stinger setup guide](../../USER_MANUAL.md#stingers) for OBS configuration.
